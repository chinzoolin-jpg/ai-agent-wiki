怎麼用

1 解壓縮整包，先雙擊 index.html，就能選 Wiki 或簡報。
2 兩個 HTML 請放在同一個資料夾，這樣頁面之間的相對連結才不會壞。
3 作業繳交說明_口語版.txt 可直接拿去改成自己的版本，補學校、學號、系級和姓名。

如果老師要求真正的網路連結
這份目前是本機 HTML，不是已經上傳完成的網站。可建立一個 GitHub repository，把 index.html、AI_Agent_Wiki.html、AI_Agent_簡報.html 放在同一層，開 GitHub Pages。公開後把 Pages 的實際網址貼到作業中。
不要直接把 sandbox 檔案連結當成永久公開網址。

備註
raw/ 六份是讀官方文章後的來源筆記，並非原始網站全文抓取。
wiki/ 有 Wiki 的索引和 7 個概念頁。
AGENTS.md 說明 ingest / query / lint 流程。
check_log.txt 有實際的檢查和修正紀錄。
